The map was built specifically for the “Random Item Skyblock” mod pack by the author RoarkCats, Ziplaw, PhoenixSC. The map is designed to fight with other players. The map is designed for 2–6 players.

## Author's platforms
Random Item Skyblock can be found across various platforms in the form of a modpack, world, or datapack alone. The datapack provides the functionality, the world provides the datapack and skyblock, and the modpack provides a convenient package. (All runs 100% vanilla)
